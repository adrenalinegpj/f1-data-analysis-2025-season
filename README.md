# Formula 1 Data Analysis Dashboard

## Project Overview

This project is an interactive Formula 1 Data Analysis Dashboard built using Microsoft Power BI.

The dashboard analyzes Formula 1 data to explore race results, driver performance, team performance, championships, and key statistics.

## Objectives

- Analyze Formula 1 race and championship data
- Compare driver performance
- Analyze constructor/team performance
- Explore race results and statistics
- Identify performance trends across seasons
- Present insights through interactive dashboards and visualizations

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization

## Dashboard Features

- Race Performance Analysis
- Driver Championship Statistics
- Constructor/Team Performance
- Driver Comparisons
- Race and Circuit Analysis
- Season Analysis
- Interactive Filters and Slicers
- Key Performance Indicators (KPIs)
